Por qué importa el HTML semántico

Usar etiquetas que describen el contenido, y no solo su aspecto, hace que una página sea más fácil de leer, de mantener y de entender tanto para las personas como para los buscadores y los lectores de pantalla.

En lugar de armar todo con <div>, conviene elegir la etiqueta que mejor representa cada parte de la página.

  • <header>: encabezado de la página o de una sección.
  • <main>: el contenido principal del documento.
  • <article>: un bloque de contenido independiente.
  • <aside>: contenido relacionado pero secundario.
  • <footer>: pie de la página o de una sección.

Primeros pasos con accesibilidad web

Una web accesible puede ser usada por la mayor cantidad de personas posible, incluso quienes navegan solo con el teclado o con un lector de pantalla.

Hay buenas prácticas simples que se pueden aplicar desde el principio y que mejoran mucho la experiencia.

  1. Usar una estructura de títulos ordenada (h1, h2, h3).
  2. Agregar aria-label a los elementos que necesiten una descripción.
  3. Asegurar que se pueda recorrer la página con el teclado usando tabindex.
  4. Escribir textos de enlace que se entiendan por sí solos.
